# Zilum

Zilum is a screenshot tool for Windows 11. Press a key, mark it up, copy.

Download it from the site: https://dbeilin.github.io/Zilum/

## Build

Zilum is one exe written in Rust. On Windows 11 with Rust 1.85 or later (MSVC toolchain):

```
cargo build --release
```

The exe is `target\release\Zilum.exe`.
